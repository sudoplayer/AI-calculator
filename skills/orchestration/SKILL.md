# 表达式计算工作流

## Overview

定义从用户输入表达式到最终数值结果的完整工作流。主智能体必须严格按此流程调度子智能体。

## Instructions

### 1. 解析表达式

- 识别括号、运算符 `+` `-` `*` `/` 与数字（含小数）。
- 遵循运算优先级：**括号内优先 → 乘除优先于加减 → 同级从左到右**。

### 2. 逐步归约

每次只处理**一个**二元运算，按优先级选出当前最该计算的一步：

| 运算符 | 子智能体 |
|--------|----------|
| `+` | `add_agent` |
| `-` | `subtract_agent` |
| `*` | `multiply_agent` |
| `/` | `divide_agent` |

调用 `task` 工具时，在 `description` 中明确写出两个操作数，例如：

```
计算 3 + 5，操作数 a=3, b=5
```

**禁止**调用 `general-purpose` 子智能体。  
**禁止**主智能体自己心算结果。

### 3. 等待子智能体返回

- 子智能体会调用对应工具并在内部触发用户确认（HITL）。
- 若子智能体返回 `REJECTED:` 开头的内容，停止后续计算并告知用户该步被拒绝。
- 若子智能体返回 `ERROR:` 开头的内容（如除零），停止并报告错误。

### 4. 代入并继续

将已确认的中间结果代回原表达式，重复步骤 2，直到表达式归约为单个数字。

### 5. 输出格式

最终回复须包含：

1. **最终结果**（单个数值）
2. **计算过程**（逐步展示，如 `(3+5)=8 → 8*2=16`）

## 示例

输入：`(3+5)*2`

1. 括号内：`add_agent` 计算 `3+5` → 得到 `8`（用户确认后）
2. 表达式变为 `8*2`
3. `multiply_agent` 计算 `8*2` → 得到 `16`（用户确认后）
4. 输出：结果 `16`，过程 `(3+5)=8 → 8*2=16`
